# Enterprise Software & Subscription Refund Policy

## Standard 30-Day Guarantee
All users (Standard and VIP) are eligible for a full refund on software subscriptions if requested within 30 days of the initial purchase or renewal date.
*   **Action:** If a user requests a refund within this 30-day window, the agent must create a LOW Severity support ticket assigned to the 'Billing' category. Inform the user that the refund will be processed in 5-7 business days.

## Requests Outside the 30-Day Window
If a user requests a refund after 30 days have passed:
*   **Standard Users:** The refund request is strictly denied. The agent must politely inform the user of the 30-day policy limit. Do NOT create a ticket or book a calendar slot.
*   **VIP Users:** VIP users may be eligible for pro-rated refunds. The agent must NOT promise a refund, but MUST use the calendar tool to book a mediation meeting with a Customer Success Manager to review the VIP's account history.

## Duplicate Charges
If any user reports being charged twice for the same billing cycle:
*   **Action:** Immediately create a MEDIUM Severity support ticket under the 'Billing' category. Instruct the user that the finance team will review the transaction and respond within 24 hours.
